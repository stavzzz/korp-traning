ИИ-ВИЗАЦИЯ: OPENCLAW · ДОПОЛНЕНИЕ К УРОКУ 1

Инструкция без антидетект-браузера и прокси

  • VPS в США + AmneziaVPN с KillSwitch
  • Firefox или любой чистый браузер + старый Gmail
  • Физический номер США через Mobile-SMS.io
  • Карта Capitalist с биллинг-адресом
  • Адаптация 1–2 дня перед покупкой подписки

01
Сетевой щит: VPS + AmneziaVPN
🔒Первый и самый важный слой: VPS-сервер в США + AmneziaVPN шифруют трафик и дают американский IP. KillSwitch блокирует интернет при обрыве VPN — ни одного байта мимо туннеля.
Купить VPS-сервер в США
Любой VPS-провайдер (AEZA, DigitalOcean и т.д.) → локация США. Сохраните IP и root-пароль.
Установить AmneziaVPN и подключиться
Скачайте Amnezia → введите IP и пароль VPS → подключитесь.
Включить KillSwitch в Amnezia
ОБЯЗАТЕЛЬНО! В настройках Amnezia включите KillSwitch — это защита от утечки реального IP при обрыве VPN-соединения.
Сменить часовой пояс на New York (EDT)
В настройках Windows / Mac смените часовой пояс на Eastern Time (US & Canada). Часы на компьютере должны совпадать с временем в США.
⚠️Важно: Часовой пояс компьютера должен совпадать с локацией VPS. Если VPS в Нью-Йорке — ставьте Eastern Time. Несовпадение — повод для подозрений.
02
Браузер и «прогрев»
🦊Используем чистый Firefox (или любой другой браузер) + старый Gmail для создания «истории» в куках. Это даёт системам анти-фрода сигнал: «обычный пользователь, не бот».
Открыть Mozilla Firefox (чистый профиль)
Создайте новый профиль в Firefox или используйте любой другой браузер. Главное — чистый профиль, без старых кук и расширений.
Войти в старый Gmail (от 1 месяца и старше)
Зайдите в свой старый Gmail, который вы НИКОГДА не использовали для Claude. Аккаунту должно быть минимум 1 месяц.
🚫Gmail НЕ должен быть светлён в Claude! Если вы хоть раз заходили с этой почтой в Claude — используйте другой Gmail.
Прогреть куки 20–30 минут
Сидите в почте 20–30 минут: листайте письма, открывайте вложения, кликайте по ссылкам. Дайте кукам «пропитаться» вашей активностью.
03
Физический номер США (Long Term)
📱Для SMS-верификации Claude нужен физический (Non-VoIP) номер США. Виртуальные номера Claude определяет и блокирует.
Арендовать Long Term номер на Mobile-SMS.io
1. Откройте Mobile-SMS.io → зарегистрируйтесь
2. Выберите категорию «Long Term Number» или «Physical / Residential» (USA)
3. Арендуйте номер → сохраните его
mobile-sms.io — аренда физических номеров
🚫VOIP-номера не берём! Виртуальные номера (Google Voice, TextNow и т.д.) — прямой путь к бану аккаунта.
04
Регистрация в Claude
⚡Регистрируемся в том же браузере, где прогрели куки. VPN должен быть включён!
Перейти на claude.ai и зарегистрироваться
1. В том же браузере откройте claude.ai
2. Нажмите «Sign up»
3. Введите Gmail и пароль
4. Подтвердите email — код придёт на почту
claude.ai — регистрация
Верифицировать номер телефона
Claude попросит номер → введите номер из Mobile-SMS.io (шаг 03). Перейдите на сайт и скопируйте SMS-код → вставьте в Claude.
Отправить тестовое сообщение
Напишите «Привет! Расскажи о себе» — получили ответ, значит аккаунт работает.
05
Адаптация (1–2 дня)
⏳Не бегите сразу покупать подписку Claude Max! Дайте системе привыкнуть к вашему «железу» и IP. Пообщайтесь с Claude на бесплатном тарифе 1–2 дня.
Пообщаться с Claude на бесплатном тарифе 1–2 дня
Задавайте вопросы, пишите промпты, пользуйтесь как обычно. Цель — система должна увидеть стабильную активность с одного IP и устройства.
✅Прошло 1–2 дня и аккаунт работает стабильно? Отлично — переходим к подготовке биллинга.
06
Адрес карты, регистрация и прогрев
🏠Создаём биллинг-адрес на основе вашего VPN IP. Stripe сравнивает локацию IP с адресом карты — если совпадают, транзакция пройдёт.
Узнать City и ZIP Code на ipinfo.io
Откройте ipinfo.io → посмотрите свой City и Postal Code (ZIP). Запишите в блокнот.
ipinfo.io — определение гео-данных IP
Найти реальный жилой адрес в Google Maps
1. Откройте Google Maps
2. Введите город и ZIP из ipinfo.io
3. Найдите любой жилой дом в этом районе
4. Скопируйте полный адрес: Street, City, State, ZIP
Google Maps — поиск адреса
Придумать американское имя
Сгенерируйте реальное американское имя на randomus.ru/name. Это имя будет на карте Capitalist.
randomus.ru/name — генератор имён
Прописать данные в биллинге карты Capitalist
В Capitalist при выпуске / настройке карты укажите:
   • Имя — американское из генератора
   • Телефон — номер из Mobile-SMS.io (шаг 03)
   • Адрес — найденный в Google Maps
07
Оплата Claude Max
💳Финальный шаг — оплата подписки Claude Max картой Capitalist. Все данные (имя, номер, адрес) должны совпадать с тем, что вы указали в биллинге карты.
Перейти в Settings → Billing → Upgrade → Max
В Claude: иконка профиля → Settings → Billing → Upgrade → выберите Max.
Ввести реквизиты карты Capitalist
Укажите:
   • Номер карты, срок, CVV — из Capitalist
   • Имя — американское имя из шага 06
   • Номер телефона — из Mobile-SMS.io (шаг 03)
   • Адрес — из Google Maps (шаг 06)
Оплатить и проверить подписку
Оплатите → перейдите в Settings → Billing → должно быть написано «Max». Готово!
🎉Поздравляем! Claude Max активирован. Теперь у вас полный доступ ко всем моделям без ограничений.
