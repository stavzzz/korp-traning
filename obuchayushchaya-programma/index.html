Модуль 02 · Безопасность

Модуль 02
Конфиденциальность и безопасность данных
Что можно загружать в ИИ, что нельзя, и как работать так, чтобы не было юридических рисков при госзаказчиках.
⏱ 60 минут 👥 Все участники 📋 Воркшоп + регламент
⚠️ Почему это критически важно: 70% команды имеют опасения по конфиденциальности. Без чёткого регламента сотрудники либо не будут использовать ИИ для реальных задач, либо будут рисковать утечкой данных. Этот модуль — фундамент всей программы.

🚫 Что НЕЛЬЗЯ загружать в ИИ — красная зона

  • Персональные данные сотрудников и контрагентов (ФИО + паспортные данные, ИНН и т.д.)
  • Документы с грифом «Коммерческая тайна» и «ДСП» (для служебного пользования)
  • Полные тексты действующих госконтрактов с реквизитами сторон
  • Проектная документация с привязкой к конкретным режимным объектам
  • Финансовые данные компании: P&L, банковские реквизиты, зарплатные ведомости
  • Информация из закрытых тендеров до их завершения
  • Внутренняя переписка с пометкой конфиденциальности

✅ Что МОЖНО загружать — зелёная зона

  • Типовые шаблоны документов (без конкретных реквизитов и имён)
  • Общедоступные НПА, СНиПы, ГОСТы, СП
  • Анонимизированные фрагменты договоров (замена имён, адресов, сумм на [КОМПАНИЯ], [АДРЕС], [СУММА])
  • Структуру и логику документа (без конкретных данных)
  • Типовые формулировки писем, приказов, положений
  • Техническую информацию из открытых источников
  • Шаблоны КС-2, КС-3 (без привязки к конкретному объекту и заказчику)

📋 Внутренний регламент (разработаем на воркшопе)

  • Whitelist инструментов: утверждённый список разрешённых ИИ-сервисов для работы
  • Классификация данных: красная / жёлтая / зелёная зона для каждого типа документов
  • Чек-лист перед загрузкой: 5 вопросов, которые сотрудник задаёт себе перед отправкой данных в ИИ

  • Ответственность: кто принимает решение в спорных ситуациях (юрист / руководитель)

Роль: Ты — деловой секретарь строительной компании, специалист по деловой переписке в B2G.

Контекст: Мы — субподрядчик. Заказчик не обеспечил строительную готовность фронта работ по договору №[НОМЕР] от [ДАТА]. Из-за этого наши бригады простаивают уже 5 рабочих дней.

Задача: Составь официальное письмо генподрядчику об отсутствии строительной готовности. Зафиксируй факт простоя, потребуй предоставить фронт работ, укажи на возможные последствия.

Формат: Официальное письмо на бланке. Стиль — деловой, юридически корректный, без эмоций. С ссылками на пункты договора и ГК РФ.

Модуль 04
Прожарка: верификация и борьба с галлюцинациями
Как проверять результат ИИ, находить ошибки, не допускать «выдуманных» данных в юридических и финансовых документах.
⏱ 90 минут 👥 Все участники 📋 Воркшоп + разбор ошибок
Из анкеты: Главное опасение команды — «ИИ привирает», «не верная подача информации», «нужно всё перепроверять». Это не баг, а фича осознанности! Но нужна система, а не слепая перепроверка.

🧠 Почему ИИ «галлюцинирует»

  • Что такое галлюцинация: ИИ генерирует правдоподобный, но несуществующий факт — номер СНиПа, пункт закона, фамилию, дату. Выглядит убедительно, но это вымысел
  • Где это критично: ссылки на НПА и СНиПы, пункты договора, расчёты, фамилии и реквизиты
  • Где менее опасно: структура документа, деловой стиль письма, генерация идей, черновики
  • Главное правило: ИИ = черновик. Человек = финальная подпись. Всегда.

Уровень 2

Уровень 4

📝 Промпты для «прожарки»

Промпт-критик: «Ты — придирчивый юридический рецензент. Проверь этот документ на:
1. Фактические ошибки (неверные ссылки на НПА, несуществующие пункты)
2. Логические противоречия
3. Юридические неточности
4. Стилистические ошибки
5. Пропущенные обязательные элементы

Для каждой проблемы: [Где ошибка] → [В чём ошибка] → [Как исправить] → [Критичность: 🔴🟡🟢]»
Промпт-верификатор для сметной документации:
«Проверь этот расчёт на арифметические ошибки, соответствие расценок нормам, полноту учёта видов работ, корректность итоговых сумм.

Выдай: [Позиция] → [Обнаруженное расхождение] → [Ожидаемое значение]»

📋 Чек-лист перед отправкой документа

  • Все ссылки на НПА / СНиПы / ГОСТы проверены в КонсультантПлюс / Гарант
  • Номера пунктов договора соответствуют реальному документу
  • Арифметика проверена (пересчёт в Excel или вручную)
  • Фамилии, реквизиты, даты — введены вручную, а не сгенерированы ИИ
  • Документ прочитан целиком, не только «выводы»
  • Стиль соответствует деловому / юридическому стандарту компании
  • Результат прогнан через «промпт-критик» (Уровень 2)
Правило команды: «ИИ пишет черновик за 2 минуты. Человек проверяет за 10 минут. Итого 12 минут вместо 60. Экономия 80% — при полном контроле качества.»

🔧 Два уровня автоматизации

Уровень 1 — Быстрые (доступны сразу)
  • Кастомные GPTs / Claude Projects: ассистенты с загруженной базой знаний — регламенты, шаблоны, НПА. Ассистент «знает» вашу компанию
  • Google Sheets + ИИ: формулы, макросы и скрипты, сгенерированные ИИ. Автосбор данных из нескольких таблиц в сводную
  • Шаблоны с переменными: ИИ заполняет шаблон договора / письма / отчёта по заданным входным данным
  • Telegram-бот ассистент: быстрый доступ к ИИ прямо из мессенджера — задаёшь вопрос по проекту, получаешь ответ с учётом контекста
Уровень 2 — Полная автоматизация (продвинутый)
  • n8n / Make / Zapier: no-code платформы для связки CRM ↔ документы ↔ ИИ ↔ уведомления. Пришла заявка в Битрикс24 → автоматически создаётся карточка, генерируется КП, отправляется письмо
  • ИИ-агент с доступом к файлам: бот, подключённый к Google Drive / корпоративному хранилищу. Имеет доступ к таблицам со сметами, юр. документам, инструкциям
  • Дашборд реального времени: автоматическое обновление данных по проектам — сроки, бюджеты, отклонения — без ручного сбора
