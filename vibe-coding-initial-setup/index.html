01
Visual Studio Code
Что это
VS Code — это IDE, «интегрированная среда разработки». Звучит сложно, а по сути — одна программа, где собрано всё для работы над проектом: файлы, редактор, дополнения. Аналогия: как Word для документов, только для проектов. Здесь и будет жить Claude Code.
Скачать и установить VS Code
Официальный сайт, выбрать свою ОС (Mac / Windows):
code.visualstudio.com
Разобраться в интерфейсе
Слева вкладки: Explorer (файлы), Extensions (расширения). Снизу — терминал (Terminal → New Terminal). Всё это покажем на уроке.
Открыть папку как проект
File → Open Folder → создать пустую папку в «Документах». Папка = проект. Claude будет работать внутри неё.
🧩 Полезные расширения (Extensions → поиск → Install):
  • Markdown Preview — просмотр .md-файлов
  • Office Viewer — Excel и PDF прямо в редакторе
02
Homebrew и Node.js — окружение
💡 Node.js — небольшая бесплатная программа. На ней работают некоторые инструменты из раздела 06. Ставим её один раз сейчас, чтобы потом всё подключалось без сюрпризов.
Что такое терминал
Программа, где команды набираются текстом, а не мышкой. Через неё ставится окружение и работает Claude Code. Команды ниже вставляются именно в терминал.

Где найти терминал:

  • 🍎 macOS: Finder → Программы → Утилиты → Терминал. Или Cmd + Пробел (Spotlight) → напечатать «Терминал» → Enter
  • 🪟 Windows: Win + X → выбрать «Терминал» или «PowerShell». Или нажать Win, напечатать «PowerShell» → Enter
🍎 macOS — сначала Homebrew (менеджер программ), затем Node.
🛑 Команды выполняем строго по очереди, по одной. Не вставляйте все три разом. Каждая следующая работает только тогда, когда предыдущая полностью закончила. Самая частая ошибка новичков именно тут.

Шаг 1. Установить Homebrew:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Установка идёт несколько минут. По дороге терминал попросит пароль от компьютера: вводите его вслепую (символы не отображаются, это нормально) и жмите Enter. Ждите, пока снова появится строка ввода.

Шаг 2. Проверить, что Homebrew встал:

brew --version

Должна появиться версия (например Homebrew 5.x.x). Только после этого идите дальше.

Если пишет command not found — выполните команду из шага 3, она и добавит Homebrew в пути, а потом снова проверьте.

Шаг 3. Добавить Homebrew в пути:

echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile eval "$(/opt/homebrew/bin/brew shellenv)"

Эта команда говорит компьютеру, где искать Homebrew.

Шаг 4. Установить Node.js:

brew install node
macOS — Node.js установлен
🪟 Windows — откройте PowerShell (как выше) и поставьте Node одним из способов:

Способ 1 — одной командой:

winget install OpenJS.NodeJS.LTS

Способ 2 — вручную: зайдите на nodejs.org, скачайте .msi (LTS-версия), при установке включите галочку «Add to PATH».

Windows — Node.js установлен
✅ Проверка: в терминале наберите node -v — покажет версию. Значит всё встало.
🔁 Обязательно перезапустите VS Code. Полностью закройте и откройте заново. Его встроенный терминал подхватывает новые программы только при запуске: без перезапуска node может «не находиться», хотя он уже установлен.

Если что-то пошло не так:

  • no such file or directory: /opt/homebrew/bin/brew — Homebrew ещё не доустановился, а команда из шага 3 уже выполнилась. Дождитесь окончания шага 1, проверьте brew --version и повторите шаг 3
  • command not found: brew — выполните шаг 3 (добавление в пути), затем проверьте снова
  • command not found: node в терминале VS Code — перезапустите VS Code целиком
03
Claude Code — установка и вход
Работаем через расширение Claude Code прямо в VS Code — без терминала, всё кнопкой.
Установить расширение Claude Code
Слева Extensions (значок кубиков) → в поиске «Claude Code» → Install. Появится панель Claude прямо в редакторе.
Войти по подписке
Откройте панель Claude Code → нажмите Sign in → войдите под своим аккаунтом Claude через браузер.
04
Базовое управление
Команды — это короткие указания для Claude Code. Пишутся в чате и начинаются со слэша /. Наберёте слэш — Claude сам покажет меню со списком. Вот основные и зачем они нужны:
КомандаЗачем нужна
Open FolderОткрыть папку проекта — Claude работает внутри неё
/contextПоказать, насколько заполнена «память» текущего диалога. Совет: одна задача — один новый диалог
/modelВыбрать модель: Opus — для сложного, Haiku — для простого и быстрого
/effortНасколько глубоко Claude думает: глубже — точнее, но дольше и дороже
/clearОчистить диалог и начать с чистого листа
/rewindОткатиться на шаг назад, если что-то пошло не так (как Ctrl+Z)
05
Скиллы
Что это
Скилл — готовая инструкция-навык, которую Claude подхватывает сам под задачу. Экономит контекст: не нужно каждый раз объяснять, как делать рутину.
Установить Superpowers — ссылкой и промптом
Набор скиллов Jesse Vincent. Ставим не командой, а просто: даём Claude Code ссылку на репозиторий obra/superpowers и промпт — он поставит сам. Вставьте этот промпт в чат Claude Code:
💬 промпт для Claude Code
Установи набор скиллов Superpowers из репозитория https://github.com/obra/superpowers — зайди по ссылке, найди инструкцию установки для Claude Code и выполни её. После установки перезапусти сессию.
💡 Даёт 20+ проверенных скиллов и команды /brainstorm, /write-plan, /execute-plan.
💎 Свой скилл ставится проще — файлом. Например наш session-handoff (грамотное завершение сессии без потери контекста) лежит в учебной папке отдельным .zip.
06
MCP — внешние сервисы
Что это
MCP — способ подключить к Claude внешние сервисы: GitHub, Google-таблицы, браузер и другое. «USB-хаб» для инструментов: подключил — и Claude умеет с ними работать.
Ставим промптом — команды руками не набираете. Копируете готовый текст, вставляете в чат Claude Code, он всё делает и проверяет сам.
🧬 AgentMemory — память агента
Агент запоминает важное между сессиями. Вставьте промпт в чат Claude Code:
💬 промпт: установить AgentMemory
Установи мне MCP-сервер AgentMemory для Claude Code. Выполни команду: claude mcp add --scope user agentmemory -- npx -y @agentmemory/mcp Затем проверь список серверов: claude mcp list. Если agentmemory в статусе Connected — скажи мне. Если ошибка — покажи её и помоги починить.
🎭 Playwright — браузер для агента
Открывает сайты, делает скриншоты, кликает, заполняет формы. Вставьте промпт:
💬 промпт: установить Playwright
Установи мне MCP-сервер Playwright для Claude Code. Выполни команду: claude mcp add --scope user playwright -- npx -y @playwright/mcp@latest Затем проверь список серверов: claude mcp list. Если playwright в статусе Connected — скажи мне. Если ошибка — покажи её и помоги починить.
📋 Task Master — разбивка задач
Делит большую задачу на подзадачи, ведёт план и прогресс. Вставьте промпт:
💬 промпт: установить Task Master
Установи мне MCP-сервер Task Master для Claude Code. Выполни команду: claude mcp add --scope user taskmaster-ai -e DEFAULT_PROVIDER=claude-code -- npx -y task-master-ai Затем проверь список серверов: claude mcp list. Если taskmaster-ai в статусе Connected — скажи мне. Если ошибка — покажи её и помоги починить.
⚠️ MCP едят контекст. Держите включённым только то, чем реально пользуетесь — лишнее отключайте.
07
GitHub
Создать аккаунт на GitHub
GitHub — это облако для проектов и кода. Регистрация: github.com
Включить двухфакторную защиту (2FA)
Это вход по второму коду с телефона — защищает аккаунт, и без неё часть установок не проходит. Как включить:
  • Откройте Settings → Password and authentication
  • Раздел Two-factor authentication → Enable
  • Выберите приложение-аутентификатор (например Google Authenticator на телефоне) → отсканируйте QR-код → введите 6-значный код
  • Сохраните резервные коды в надёжном месте
Пошагово покажу на скринкасте.
📱 Нет приложения-аутентификатора на телефоне? Скачайте бесплатное Google Authenticator — оно и будет показывать 6-значные коды. Выберите по своему телефону:
  • 🍎 iPhone (iOS): App Store
  • 🤖 Android: Google Play
Выпустить токен доступа (PAT)
Токен — это ключ-пароль, которым Claude заходит в ваш GitHub. Создать: fine-grained token с доступом к нужным репозиториям. Пошагово — на скринкасте.
Подключить GitHub к Claude Code
Вставьте промпт в чат Claude Code — он подключит GitHub и сам спросит ваш токен:
💬 промпт: подключить GitHub
Подключи мне официальный GitHub к Claude Code. Спроси у меня токен доступа (PAT), затем выполни команду, подставив мой токен вместо МОЙ_ТОКЕН: claude mcp add --transport http github https://api.githubcopilot.com/mcp/ --header "Authorization: Bearer МОЙ_ТОКЕН" Затем проверь список серверов: claude mcp list. Если github в статусе Connected — скажи мне. Если ошибка — покажи её и помоги починить.
🔒 Токен — это ключ. Не выкладывайте его в чат, скриншот или git. Утёк — сразу отзовите и выпустите новый.
08
Защита от разрушительных команд
Claude умеет выполнять команды на компьютере — это удобно, но по ошибке он может, например, удалить нужные файлы. Поэтому ставим защиту в два уровня:
Уровень 1 — встроенная защита (обязательно)
Claude по умолчанию спрашивает разрешение перед каждым действием. А самые опасные операции — например удаление файлов — можно запретить ему совсем. Настроим вместе на уроке.
Уровень 2 — программа-сторож DCG (по желанию)
Отдельная бесплатная защита: блокирует опасные команды ещё до запуска. Проще всего поставить промптом:
💬 промпт: поставить защиту DCG
Установи и настрой мне DCG — защиту от опасных команд для Claude Code, из репозитория https://github.com/Dicklesworthstone/destructive_command_guard. Я новичок — веди по шагам простыми словами, подключи защиту как положено и в конце проверь, что она работает.

Что DCG ловит:

  • удаление файлов и папок целиком
  • опасные действия с историей проекта (откат, затирание)
  • опасные команды с базами данных и серверами

Чего НЕ ловит:

  • действия злоумышленника — защиту можно обойти
  • когда Claude правит файлы напрямую
  • команды, спрятанные внутри скриптов
