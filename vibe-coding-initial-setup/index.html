01
Visual Studio Code
Что это
Редактор кода. Для нас — окно, в котором мы открываем папку проекта, видим файлы и держим встроенный терминал. В нём же будет жить Claude Code.
Скачать и установить VS Code
Официальный сайт, выбрать свою ОС (Mac / Windows):
code.visualstudio.com
Разобраться в интерфейсе
Слева вкладки: Explorer (файлы), Extensions (расширения). Снизу — терминал (Terminal → New Terminal). Всё это покажем на уроке.
Открыть папку как проект
File → Open Folder → создать пустую папку в «Документах». Папка = проект. Claude будет работать внутри неё.
🧩 Полезные расширения (Extensions → поиск → Install):
  • Markdown Preview — просмотр .md-файлов
  • Office Viewer — Excel и PDF прямо в редакторе
02
Homebrew и Node.js — окружение
💡 Для самого Claude Code Node не нужен. Но MCP-серверы (раздел 06) запускаются через npx — а это Node. Поэтому окружение ставим сразу.
Что такое терминал
Программа, где команды набираются текстом, а не мышкой. Через неё ставится окружение и работает Claude Code. Команды ниже вставляются именно в терминал.

Где найти терминал:

  • 🍎 macOS: Finder → Программы → Утилиты → Терминал. Или Cmd + Пробел (Spotlight) → напечатать «Терминал» → Enter
  • 🪟 Windows: Win + X → выбрать «Терминал» или «PowerShell». Или нажать Win, напечатать «PowerShell» → Enter
🍎 macOS — сначала Homebrew (менеджер программ), затем Node. В Терминале выполните по очереди:

1. Установить Homebrew:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

2. Добавить Homebrew в пути:

echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile eval "$(/opt/homebrew/bin/brew shellenv)"

3. Установить Node.js:

brew install node
macOS — Node.js установлен
🪟 Windows — откройте PowerShell (как выше) и поставьте Node одним из способов:

Способ 1 — одной командой:

winget install OpenJS.NodeJS.LTS

Способ 2 — вручную: зайдите на nodejs.org, скачайте .msi (LTS-версия), при установке включите галочку «Add to PATH».

Windows — Node.js установлен
✅ Проверка (в терминале): node -v покажет версию. Если Node только что поставили — перезапустите VS Code, чтобы терминал подхватил новые пути.
03
Claude Code — установка и вход
Два способа работы, они дополняют друг друга: расширение в VS Code (визуально, кнопкой) и терминал (полный набор команд). Ставим оба.
Расширение Claude Code в VS Code
Слева Extensions → в поиске «Claude Code» → Install. Появится панель Claude прямо в редакторе.
macOS — терминальный Claude Code
curl -fsSL https://claude.ai/install.sh | bash
Windows — терминальный Claude Code
В PowerShell:
irm https://claude.ai/install.ps1 | iex
🪟 Windows: доставьте Git for Windows — без него Claude Code работает через PowerShell вместо Bash.
Проверить установку
claude --version claude doctor
claude doctor проверит окружение и подскажет, если что-то не так.
Войти по подписке
Запустить claude в папке проекта → команда /login → войти корпоративным Team-аккаунтом через браузер.
04
Базовое управление
Всё это разберём на уроке руками — здесь просто карта команд, чтобы было понятно, что мы делаем.
КомандаЧто делает
Open FolderОткрыть папку — Claude работает внутри неё
/contextПоказать контекст и токены. Правило: одна задача — один диалог
/modelВыбрать модель: Opus (сложное) / Sonnet / Haiku (быстрое)
/effortУровень «размышления» — глубже думает, но дольше и дороже
/clearОчистить контекст, начать с чистого листа
/rewindОткатиться к предыдущему состоянию (чекпоинт)
⌨️ Все команды начинаются со слэша / — наберите его, и появится меню со списком.
05
Скиллы
Что это
Скилл — готовая инструкция-навык, которую Claude подхватывает сам под задачу. Экономит контекст: не нужно каждый раз объяснять, как делать рутину.
Установить Superpowers — одной командой
Набор скиллов Jesse Vincent (obra/superpowers). Ставится из официального маркетплейса Anthropic — он уже подключён в Claude Code, отдельных шагов не нужно:
/plugin install superpowers@claude-plugins-official
Даёт 20+ проверенных скиллов и команды /brainstorm, /write-plan, /execute-plan.
🔑 Плагины тянутся с GitHub. Если установка спотыкается — залогиньтесь в GitHub и включите 2FA (двухфакторную аутентификацию). Как — покажу на уроке.
💎 Свой скилл ставится проще — файлом. Например наш session-handoff (грамотное завершение сессии без потери контекста) лежит в учебной папке отдельным .zip.
06
MCP — внешние сервисы
Что это
MCP — способ подключить к Claude внешние сервисы: GitHub, Google-таблицы, браузер и другое. «USB-хаб» для инструментов: подключил — и Claude умеет с ними работать.
🆕 Обновлённый синтаксис.
  • Локальные серверы: claude mcp add … -- npx …
  • Удалённые: claude mcp add --transport http … <url>
  • Флаг --scope user — доступно во всех проектах
AgentMemory — долгая память агента
claude mcp add --scope user agentmemory -- npx -y @agentmemory/mcp
Playwright — управление браузером
claude mcp add --scope user playwright -- npx -y @playwright/mcp@latest
Task Master — разбивка задач
claude mcp add --scope user taskmaster-ai -e DEFAULT_PROVIDER=claude-code -- npx -y task-master-ai
Проверить подключённые MCP
Команда /mcp — покажет список серверов и их статус.
⚠️ MCP едят контекст. Держите включённым только то, чем реально пользуетесь — лишнее отключайте.
07
GitHub
Создать аккаунт на GitHub
github.com — там же хранятся проекты и база знаний.
Выпустить токен PAT
Personal Access Token — ключ, которым Claude ходит в ваш GitHub. Настройки → fine-grained token с доступом к нужным репозиториям.
Подключить официальный GitHub MCP
Вставьте свой токен вместо YOUR_GITHUB_PAT:
claude mcp add --transport http github https://api.githubcopilot.com/mcp/ \ --header "Authorization: Bearer YOUR_GITHUB_PAT"
🔒 Токен — это ключ. Не выкладывайте его в чат, скриншот или git. Утёк — сразу отзовите и выпустите новый.
08
Защита от разрушительных команд
Claude запускает команды в терминале. Ошибка агента (rm -rf, git reset --hard) может стереть работу. Два слоя защиты:
Слой 1 — встроенный (обязательно)
Режим разрешений Ask (Claude спрашивает перед действием) + правила deny в settings.json на .env, rm -rf, sudo. Настроим на уроке.
Слой 2 — плагин DCG (по желанию)
Хук-перехватчик на Rust: блокирует опасные команды до запуска. macOS / Linux:
curl -fsSL https://raw.githubusercontent.com/Dicklesworthstone/destructive_command_guard/main/install.sh | bash
Что DCG умеет и чего НЕ умеет

Ловит:

  • rm -rf вне временных папок
  • git reset --hard, git clean -f, force-push
  • опасные команды баз данных, Docker, Terraform

НЕ ловит:

  • злонамеренные действия — хук можно обойти
  • правку файлов инструментами Write/Edit
  • команды внутри скриптов

Вывод: хорошая добавка, но не замена слоя 1. Ставьте как дополнение, а не вместо встроенной защиты.
