01
Введение: вайб-кодинг и CLI (Терминал)
📖 Теоретический блок — смотрим вместе с видеоуроком. Здесь собраны ключевые понятия, к которым можно вернуться в любой момент.
Вайб-кодинг (Vibe Coding)
Современный подход к разработке: вы выступаете не как программист, а как архитектор. Передаёте идею и логику текстом, а всю работу по написанию, тестированию и отладке кода делает ИИ-агент.
📌 Вы описываете, что хотите получить, — агент сам пишет код, исправляет ошибки и выдаёт готовый результат. Вы направляете процесс и принимаете работу.
CLI — Command Line Interface
Текстовый способ взаимодействия с компьютером или сервером. Вместо кликов мышкой — чёткие текстовые команды в Терминале.
📌 Команда mkdir new_folder мгновенно создаст новую папку. Для нейросетей Терминал — идеальная среда: чистый текстовый ввод и вывод. Агент может сам запустить скрипт, прочитать ошибку и тут же исправить её.
Markdown
Язык разметки текста с помощью простых символов: # для заголовков, - для списков, | для таблиц, ``` для кода.
📌 Нейросети обожают Markdown: он позволяет структурировать мысли без траты токенов на сложную вёрстку, а результат получается предсказуемым и легко читаемым для человека.
02
Архитектура системы — как всё связано
🗺️ Это «карта» того, как все компоненты будут взаимодействовать друг с другом после успешной настройки. Сверяйтесь с ней по ходу урока.
┌─────────────────┐ │ Claude Code │ │ (VS Code) │ └────────┬────────┘ │ SSH ▼ ┌───────────┐ ┌──────────────────┐ ┌────────────────┐ │ Telegram │───▶│ OpenClaw │───▶│ OpenRouter │ │ (Боты) │◀───│ (VPS) │◀───│ (600+ моделей) │ └───────────┘ └──────┬───┬──────┘ └────────────────┘ │ │ │ │ ┌────────────────┐ │ └───────────▶│ OpenAI Codex │ │ ◀────────────│ (ChatGPT) │ │ └────────────────┘ ┌──────┴───────┐ │ Whisper ▲ │ GroQ (free) │ │ + OpenAI ($)▼ └──────────────┘

Поток данных:

1. Claude Code (VS Code на вашем компьютере) подключается к VPS по SSH — устанавливает OpenClaw, настраивает конфиги, создаёт агентов.

2. Вы отправляете сообщение (текст или голос) боту в Telegram.

3. Если сообщение голосовое — Whisper (OpenAI или Groq) конвертирует речь в текст.

4. OpenClaw обрабатывает запрос и отправляет в OpenAI Codex (ChatGPT) или OpenRouter (бесплатные модели).

5. Модель генерирует ответ → он возвращается вам в Telegram.

Шаг 1. Установка Node.js — критически необходим для работы скиллов.

🍎 Инструкция для macOS

Откройте стандартный Терминал Mac (Finder → Программы → Утилиты → Терминал) и выполните по очереди:

1. Установка Homebrew:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

2. Добавляем Homebrew в пути:

echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile eval "$(/opt/homebrew/bin/brew shellenv)"

3. Установка Node.js:

brew install node

4. Пути для npm:

echo 'export PATH="$HOME/.npm-global/bin:$PATH"' >> ~/.zshrc source ~/.zshrc
🪟 Инструкция для Windows

Как открыть терминал на Windows: нажмите Win + X → выберите «Терминал (Администратор)» или «PowerShell (Администратор)». Или: нажмите Win, введите PowerShell, правой кнопкой → «Запуск от имени администратора».

Зайдите на nodejs.org и скачайте установщик .msi (LTS версия). При установке убедитесь, что включена опция «Add to PATH».

Альтернативный путь (PowerShell от имени администратора):

winget install OpenJS.NodeJS.LTS

После установки обязательно полностью перезапустите VS Code, чтобы терминал подтянул новые переменные PATH.

07
Выбор и подключение LLM-провайдеров
🧠 Прямо в запущенном мастере настройки (из шага 06) вам предложат выбрать, чьи нейросети будет использовать ваш бот. Ниже — два варианта.

Вариант А: OpenAI Codex (подписка ChatGPT) ✅ ОСНОВНОЙ

OpenAI официально разрешает использование подписки в OpenClaw. Если у вас ChatGPT Plus или Pro — это лучший и самый умный выбор.

Подключить OpenAI Codex (ChatGPT)
1. В мастере настройки выберите openai-codex
2. В терминале появится ссылка на авторизацию
3. Откройте её в браузере → войдите в аккаунт ChatGPT
4. Дождитесь подтверждения в терминале
Установить режим reasoning: High или Extra High
Чтобы бот давал максимально глубокие и точные ответы, выберите High (рекомендуется) или Extra High (модель думает дольше, но ответы ещё глубже).

Для High:
openclaw config set agents.defaults.models."openai-codex/gpt-5.4".params.reasoning.effort "high"
Для Extra High:
openclaw config set agents.defaults.models."openai-codex/gpt-5.4".params.reasoning.effort "extra_high"
Лимиты: ChatGPT Plus ($20/мес) — ~5 часов активной работы в неделю. ChatGPT Pro ($200/мес) — безлимит. Когда квота закончится, бот переключится на резервную модель (fallback).

Вариант Б: OpenRouter (агрегатор) ✅ ВТОРОЙ ВАРИАНТ

Доступ к 600+ моделям (Claude, GPT, Gemini, DeepSeek, Qwen) с оплатой за каждый запрос. Идеально в качестве fallback — это резервная модель, которая автоматически подхватывает работу, если основная (ChatGPT) недоступна или закончились лимиты.

Мы уже зарегистрировались на OpenRouter и пополнили баланс на $15 в уроке 2. Пришло время использовать ваш API-ключ от OpenRouter.

Подключить OpenRouter к OpenClaw
В мастере настройки выберите провайдера OpenRouter → вставьте ваш API-ключ из урока 2.
Если забыли ключ: зайдите на openrouter.ai/settings/keys и скопируйте существующий или создайте новый.

Выбор резервной модели (Fallback): после мастера настройки отправьте в Claude Code задачу для установки бесплатной модели от Qwen. Точный ID модели можно найти на сайте:
openrouter.ai/models — каталог моделей
08
SSH-туннель для Web UI
🔒 Чтобы безопасно управлять OpenClaw через браузер, пробрасываем защищённый SSH-туннель с сервера на ваш компьютер.
Узнать токен авторизации
В терминале на сервере (VPS) выполните:
cat ~/.openclaw/openclaw.json | grep token
Скопируйте полученную строку и сохраните — она нужна для входа в WebUI.
Запустить SSH-туннель
Откройте НОВОЕ окно терминала на вашем компьютере (не на сервере!).

Проверка порта (macOS):
lsof -i :18789
Проверка порта (Windows):
netstat -ano | findstr :18789
(Если ничего не вывело — порт свободен. Если занят — используйте 38789)

Запуск туннеля:
ssh -N -L 18789:127.0.0.1:18789 root@IP_АДРЕС
После ввода пароля экран «зависнет» — это нормально, туннель работает в фоне. Не закрывайте окно!
Открыть Web UI в браузере
Перейдите по ссылке, подставив ваш токен:
http://localhost:18789/#token=ВАШ_ТОКЕН
(Если использовали порт 38789: http://localhost:38789/#token=ВАШ_ТОКЕН)
💡 Как закрыть зависший туннель

Windows: просто закройте окно PowerShell крестиком.

macOS: нажмите Ctrl + C в окне терминала с туннелем, либо в новом окне:

lsof -ti:18789 | xargs kill -9

Голосовые сообщения: OpenAI Whisper + Groq Whisper
🎙️ OpenAI Whisper — основная модель (платная, самая точная). Groq Whisper — резервная (бесплатная, подхватывает работу, если OpenAI недоступен). Все ключи и конфиги устанавливаем через Claude Code.
Получить API-ключ OpenAI и пополнить баланс
1. Зайдите на платформу OpenAI под своим логином ChatGPT
2. Создайте новый API-ключ (Create new secret key)
3. Пополните баланс в Billing — хотя бы на $10–$20
4. Скопируйте ключ (начинается с sk-...)
platform.openai.com — API-ключи
Получить бесплатный API-ключ Groq
1. Зарегистрируйтесь на Groq
2. Перейдите в API Keys → Create API Key
3. Скопируйте ключ (начинается с gsk_...)
console.groq.com — регистрация
Настроить Whisper через Claude Code
Вставьте свои ключи OpenAI (sk-...) и Groq (gsk_...) в промпт ниже, скопируйте его и отправьте агенту в чат Claude Code внутри VS Code.
📋 Промпт для настройки голоса (отправить в Claude Code)
Выполни следующие задачи по настройке голосовых сообщений: 1. Добавь ключ OpenAI: openclaw config set env.OPENAI_API_KEY "sk-ВАШ_КЛЮЧ" 2. Добавь ключ Groq: openclaw config set env.GROQ_API_KEY "gsk_ВАШ_КЛЮЧ" 3. Найди конфигурационный файл ~/.openclaw/openclaw.json. Отредактируй в нём секцию tools.media.audio следующим образом: - Убедись, что параметр enabled установлен в true. - Настрой массив models строго в таком порядке: Первый (основной) провайдер: provider "openai", model "whisper-1", type "provider". Второй (резервный) провайдер: provider "groq", model "whisper-large-v3", type "provider". 4. После изменения файла выполни: openclaw gateway restart Проверь логи и подтверди, что ошибки конфигурации отсутствуют.
Протестировать голосовое сообщение
Откройте бота в Telegram → зажмите микрофон → скажите: «Привет, агент! Какая сегодня погода?» → отправьте.
Бот должен прислать расшифровку аудио и ответ от модели. ✅

Если ошибка — отправьте агенту в Claude Code: Проверь логи сервера командой openclaw logs --follow и найди ошибку в модуле audio.

Показ остатка лимитов ChatGPT в Telegram-боте

📋 Промпт: настройка лимитов ChatGPT
Выполни следующие 4 шага для настройки отображения лимитов ChatGPT в Telegram-боте. ШАГ 1: Создай скрипт обновления лимитов. Создай файл /usr/local/bin/openclaw-usage-writer.sh со следующим содержимым: #!/bin/bash output=$(/usr/bin/openclaw models status 2>/dev/null) line=$(echo "$output" | grep 'openai-codex usage:') if [ -n "$line" ]; then raw=$(echo "$line" | sed 's/.*openai-codex usage: //') day_pct=$(echo "$raw" | grep -oP '(\d+)% left' | head -1 | grep -oP '\d+') day_time=$(echo "$raw" | grep -oP '⏱[^·]+' | head -1 | sed 's/⏱//' | xargs) week_pct=$(echo "$raw" | grep -oP 'Week\s+\K\d+') week_time=$(echo "$raw" | grep -oP 'Week.*⏱\K.*' | xargs) echo "день ${day_pct}% · ⏱ ${day_time} | неделя ${week_pct}% · ⏱ ${week_time}" > ~/.openclaw/workspace/gpt-usage.txt fi Сделай файл исполняемым: chmod +x /usr/local/bin/openclaw-usage-writer.sh ШАГ 2: Добавь в cron автообновление каждую минуту: (crontab -l 2>/dev/null; echo '* * * * * /usr/local/bin/openclaw-usage-writer.sh') | crontab - Запусти скрипт первый раз вручную и покажи содержимое gpt-usage.txt. ШАГ 3: Добавь в конец файла ~/.openclaw/workspace/IDENTITY.md следующий блок: ## Обязательный футер КРИТИЧЕСКИ ВАЖНО: Перед КАЖДЫМ ответом ты ОБЯЗАН заново прочитать файл gpt-usage.txt из workspace через инструмент read/fs. НИКОГДА не используй ранее прочитанные данные — они устаревают каждую минуту. ВСЕГДА делай свежее чтение файла. В самом конце КАЖДОГО сообщения добавь РОВНО одну конструкцию: ───────────────── 💬 [свежее содержимое файла gpt-usage.txt] Правила: - КАЖДЫЙ РАЗ читай файл заново — данные меняются каждую минуту - Вставляй содержимое КАК ЕСТЬ после 💬 - Футер должен быть ОДИН РАЗ в самом конце - НЕ добавляй к футеру ничего от себя - Разделитель ───────────────── на отдельной строке ШАГ 4: Подтверди, что всё настроено корректно: скрипт работает, cron добавлен, IDENTITY.md обновлён.

🔧 Как это работает

Cron-скрипт каждую минуту запускает openclaw models status и записывает данные в файл gpt-usage.txt внутри workspace агента.

Агент перед каждым ответом заново читает этот файл и добавляет футер.

Важно: файл должен лежать внутри ~/.openclaw/workspace/, иначе sandbox-ограничения не дадут его прочитать. При смене модели (не OpenAI Codex) нужно обновить grep-паттерн в скрипте.

Организация работы в Telegram: группа с топиками
💡 Вести диалог с агентом в одном длинном чате — верный путь к хаосу: контексты смешаются, агент будет путать код с рецептом пирога. Правильный подход — создать Telegram-группу, включить в ней Топики (Темы) и общаться с ботом там. Каждая тема — изолированная сессия.
Создать группу и включить Темы
1. Создайте новую группу в Telegram (например, «Мой Агент»)
2. Настройки группы → Изменить → включите Темы (Topics)
3. Добавьте в группу вашего бота
Узнать chat_id группы
Добавьте в группу бота @userinfobot — он сразу пришлёт chat_id вашей группы (число с минусом, например -100123456789). Скопируйте ID и удалите бота из группы.
Узнать свой user ID
Напишите боту @userinfobot в личку — он пришлёт ваш числовой ID (просто число, без минуса). Сохраните его — понадобится для конфига.
Отключить Privacy Mode у бота в @BotFather
Идём в @BotFather → /mybots → выбрать бота → Bot Settings → Group Privacy → Turn off. Без этого бот не будет видеть сообщения в группе.
Назначить бота Администратором группы
Настройки группы → Администраторы → добавьте вашего бота → включите все права (Change Group Info, Delete Messages, Ban Users, Invite Users via Link, Pin Messages, Manage Topics, Manage Video Chats, Add New Admins). Remain Anonymous — выключено.
⚠️ Частые ошибки, которых нужно избежать:
• НЕ путай group ID (начинается с -100...) и user ID (просто число) — это разные поля в конфиге
• Group ID идёт в groupAllowFrom, User ID идёт в allowFrom
• Если забыть добавить user ID в allowFrom — бот будет отвечать «not authorized»
• Privacy Mode должен быть отключён в @BotFather (см. чекбокс выше)
