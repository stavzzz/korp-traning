01
VPN — базовый туннель
🔒Первый слой защиты: шифруем трафик и скрываем реальное местоположение. VPS в США → Amnezia VPN → KillSwitch включён.
Купить VPS-сервер в США на AEZA
Тариф: 2 vCPU / 4 ГБ RAM / 60 ГБ SSD, Ubuntu 24.04, локация США. Сохраните IP и root-пароль.
aeza.net — покупка VPS-сервера
Установить Amnezia VPN и подключиться к серверу
Скачайте Amnezia (файлы из основного чеклиста) → введите IP и пароль → подключитесь → включите KillSwitch (защита от утечек при разрыве VPN).
02
Антидетект-браузер
🕶Второй слой: подменяем аппаратные отпечатки браузера. Dolphin{anty} создаёт «чистый» профиль с уникальными характеристиками — сайты не увидят ваш настоящий браузер.
Скачать и установить Dolphin{anty}
Бесплатный тариф. Зарегистрируйтесь → скачайте приложение → установите.
dolphin-anty.com — антидетект-браузер
Создать профиль в Dolphin
В Dolphin: «Создать профиль» → Таймзона и Язык — Auto → сохраните → запустите профиль. Прокси пока не подключаем — добавим на шаге 04.
03
Почта: Gmail или Hotmail
✉️⚠️ Ни в коем случае не используйте Gmail, который вы когда-либо подключали к Claude! Нужен чистый, свежий Gmail или Hotmail, который никогда не использовался для регистрации в аккаунте Claude. Proton Mail запрещён — высокий риск блокировки платежа.
🚫Запрещено: Proton Mail, Tutanota и другие «анонимные» почтовые сервисы. Только Gmail или Hotmail.
Зарегистрировать Gmail или Hotmail
1. Зарегистрируйте новую почту в антидетект-браузере с включённым VPN США
2. Откройте Gmail или Hotmail
3. Если Hotmail — выберите домен @hotmail.com в выпадающем списке
4. Придумайте адрес и пароль → сохраните
⚠️Если Google или Microsoft блокирует регистрацию — сначала выполните Шаг 04 (подключите резидентский прокси) и только потом создавайте почту.
Включить двухфакторную аутентификацию (2FA)
Зайдите в настройки безопасности почты → включите 2FA → сохраните Recovery Code в надёжном месте.
04
Резидентский прокси США
🌐Получаем домашний IP (Comcast). Это фундамент. Без этого этапа все остальные шаги бессмысленны. Claude, Stripe и другие сервисы должны видеть обычного пользователя дома в США.
Купить статический резидентский прокси США (Comcast)
Зайдите в CyberYozh → Резидентские прокси → Статические → США (Comcast). Скопируйте SOCKS5 данные (IP:Port:Login:Password).
cyberyozh.com — резидентские прокси
Подключить прокси к профилю Dolphin
В Dolphin: откройте настройки профиля → Proxy → SOCKS5 → вставьте данные прокси → сохраните → запустите профиль.
05
Глубокий аудит и сбор данных (Triple Check)
🎯Финальная проверка «капсулы» на герметичность и сбор гео-данных. Все проверки — внутри профиля Dolphin с подключённым резидентским прокси!
Whoer.net — анонимность 100%
Убедитесь, что анонимность 100%. Если меньше — проверьте настройки времени в профиле Dolphin (должно быть Auto).
whoer.net — проверка анонимности
PixelScan.net — статус Consistent + сбор гео-данных
Статус должен быть Consistent (зелёный).

⚠️ ВАЖНО: Найдите раздел Location и выпишите в блокнот три параметра:
   • City — Город
   • State — Штат
   • ZIP Code — Индекс

Эти данные понадобятся на следующем шаге!
pixelscan.net — проверка отпечатков
Scamalytics.com — Fraud Score ниже 20
Проверьте Fraud Score вашего IP. Допустимое значение — ниже 20. Если индикатор красный — ваш резидентский прокси скомпрометирован, его нужно заменить.
scamalytics.com — проверка Fraud Score
✅Все три проверки прошли и гео-данные записаны? Отлично — «капсула» герметична. Переходим к созданию легенды.
06
Генерация «белой» личности (Billing Address)
🏠Создание физического адреса вашей легенды на основе данных резидентского прокси. Stripe сравнивает локацию прокси с адресом карты — если данные из PixelScan и Google Maps совпадут, транзакция пройдёт без подозрений.
Найти жилой дом в Google Maps по данным PixelScan
1. Внутри Dolphin откройте Google Maps
2. Связка с PixelScan: в строке поиска введите Город и ZIP-код, которые вы получили на этапе 05
3. Поиск дома: выберите на карте любой жилой дом (Residential building). Избегайте бизнес-центров, почтовых отделений и парков
4. Фиксация данных: кликните на здание и скопируйте полный адрес
Google Maps — открыть карту
Сохранить адрес в блокнот
Запишите полный адрес:
   • Street + House number — улица и номер дома
   • City — город (должен совпадать с PixelScan!)
   • State — штат
   • ZIP Code — индекс (должен совпадать с PixelScan!)

Этот адрес вы введёте:
   • В Capitalist при создании карты (шаг 08)
   • В Claude при оплате подписки (шаг 10)
07
Резидентский номер телефона США
📱Резидентский физический номер США (Non-VoIP) (Non-VoIP). Такие номера проходят верификацию Claude без проблем, в отличие от виртуальных.
Арендовать номер США на MobileSMS.io
1. Откройте MobileSMS.io → зарегистрируйтесь
2. Перейдите в Long Term Rentals → USA
3. Тип: строго Physical / Non-VoIP
4. Выберите сервис: Claude / Anthropic
5. Арендуйте номер → сохраните его
mobilesms.io — аренда физических номеров США
08
Виртуальная карта Capitalist
💳Белая дебетовая карта USD с американским биллинг-адресом. Требует верификацию по паспорту (KYC) — именно поэтому она надёжнее «серых» карт и не вызывает подозрений у Stripe.
Зарегистрироваться на Capitalist
Откройте capitalist.net → создайте аккаунт.
capitalist.net — платёжная платформа
Пройти верификацию (KYC)
В личном кабинете: загрузите скан загранпаспорта (или ID) + сделайте селфи. Без верификации выпуск карт недоступен. Обычно занимает 1–2 рабочих дня.
Выпустить виртуальную карту USD
После KYC: выберите виртуальную карту USD (Debit/Corporate) → выпустите. Срок действия карты Capitalist — 1 год.
Указать биллинг-адрес США
Укажите американский адрес из шага 06 как биллинг-адрес при выпуске карты. Город и штат должны совпадать с локацией прокси.
Пополнить карту на ~$110
Claude Max $100 + запас $10 на обслуживание карты. Проверьте тип карты на binlist.net — должно быть Debit.
💡Альтернатива: Сервис CardsPro — виртуальные карты со сроком действия 6 лет. Подходит тем, кто хочет долгосрочную карту без ежегодного перевыпуска. Работает по тому же принципу: KYC + выпуск карты USD + биллинг-адрес из шага 06.
Альтернатива: выпустить карту на CardsPro (срок — 6 лет)
1. Откройте cardspro.biz → вход доступен по данным аккаунта Capitalist
2. Выпустите карту USD
3. В поле Billing Address укажите адрес из шага 06
4. Пополните карту на ~$110
cardspro.biz — виртуальные карты (6 лет)
09
Регистрация Claude
⚡Всё делаем внутри Dolphin — не в обычном Chrome! Держите вкладку MobileSMS открытой для приёма кода.
Зарегистрироваться в Claude
1. В Dolphin откройте claude.ai → «Sign up»
2. Введите почту Gmail/Hotmail из шага 03 (email + пароль отдельно, НЕ «Continue with Google»)
3. Подтвердите email — код придёт на вашу почту
claude.ai — регистрация
Верифицировать номер телефона
Claude попросит номер → введите номер из MobileSMS (шаг 07). Перейдите в MobileSMS и скопируйте пришедший SMS-код → вставьте в Claude.
Отправить тестовое сообщение
Напишите «Привет! Расскажи о себе». Получили ответ — аккаунт работает!
10
Оплата Claude Max ($100/мес)
💎Claude Max — полный доступ ко всем моделям без ограничений. Очень важная подписка для интенсива. Если вы её не купите, то ваш OpenClaw будет работать менее эффективно.
Оплатить Claude Max
1. В Dolphin (Claude открыт) → иконка профиля → Settings → Billing
2. Upgrade → выберите Max
3. Введите реквизиты карты Capitalist из шага 08
4. Биллинг-адрес — тот же американский адрес, что сохранили на шаге 06
5. Номер телефона — номер из MobileSMS (шаг 07)
6. Оплатите → готово!
Проверить подписку
Settings → Billing → должно быть написано «Max».
Войти на платформу Claude
Обязательный шаг для API-токена и подключения к OpenClaw.
platform.claude.com — платформа для API-токена
