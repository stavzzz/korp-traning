01
VPN — базовый туннель
🔒Первый слой защиты: шифруем трафик и скрываем реальное местоположение. VPS в США → Amnezia VPN → KillSwitch включён.
Купить VPS-сервер в США на AEZA
Тариф: 2 vCPU / 4 ГБ RAM / 60 ГБ SSD, Ubuntu 24.04, локация США. Сохраните IP и root-пароль.
aeza.net — покупка VPS-сервера
Установить Amnezia VPN и подключиться к серверу
Скачайте Amnezia (файлы из основного чеклиста) → введите IP и пароль → подключитесь → включите KillSwitch (защита от утечек при разрыве VPN).
02
Антидетект-браузер
🕶Второй слой: подменяем аппаратные отпечатки браузера. Dolphin{anty} создаёт «чистый» профиль с уникальными характеристиками — сайты не увидят ваш настоящий браузер.
Скачать и установить Dolphin{anty}
Бесплатный тариф. Зарегистрируйтесь → скачайте приложение → установите.
dolphin-anty.com — антидетект-браузер
Создать профиль в Dolphin
В Dolphin: «Создать профиль» → Таймзона и Язык — Auto → сохраните → запустите профиль. Прокси пока не подключаем — добавим на шаге 04.
03
Почта Proton Mail
✉️Анонимный почтовый ящик. Регистрация строго внутри запущенного профиля Dolphin — так почта привязывается к чистому отпечатку, а не к вашему обычному браузеру.
Зарегистрировать Proton Mail
1. Запустите профиль Dolphin (не обычный Chrome!)
2. Откройте proton.me/mail → «Create account»
3. Придумайте адрес (имя@proton.me) и пароль
4. Сохраните данные
proton.me/mail — защищённая почта
04
Резидентный прокси США
🌐Третий слой: получаем домашний IP настоящего американского провайдера (не дата-центровый). Claude, Stripe и другие сервисы видят обычного пользователя дома в США.
Купить резидентный прокси США на CyberYozh
Зайдите в CyberYozh → Резидентские прокси → Статические → США → выберите провайдера US Comcast. Скопируйте SOCKS5 данные (IP:Port:Login:Password).
app.cyberyozh.com — резидентные прокси
Подключить прокси к профилю Dolphin
В Dolphin: откройте настройки профиля (создан на шаге 02) → в разделе Proxy вставьте SOCKS5 данные → сохраните → перезапустите профиль. Теперь весь трафик Dolphin идёт через домашний IP в США.
05
Генерация «белой» личности (Billing Address)
🏠Критически важный шаг! Нужно найти реально существующий адрес в США, который совпадает с локацией вашего прокси. Без этого Stripe отклонит оплату.
Узнать точную локацию прокси
1. Запустите профиль Dolphin с подключённым прокси US Comcast
2. Откройте ipinfo.io
3. Запишите три параметра:
   • City — город (например, Jersey City)
   • Region/State — штат (например, New Jersey)
   • Postal/ZIP — индекс (например, 07302)
ipinfo.io — определение локации IP
Найти реальный жилой дом в Google Maps
1. Не закрывая Dolphin, откройте Google Maps
2. Введите в поиск свой город и штат (например: Jersey City, NJ)
3. Найдите любой жилой квартал — лучше одноэтажную застройку или апартаменты
4. Кликните на здание → скопируйте полный адрес

Пример:
   • Street: 155 Montgomery St
   • City: Jersey City
   • State: NJ (New Jersey)
   • ZIP Code: 07302
Сохранить адрес в блокнот
Запишите: Street, City, State, ZIP. Этот адрес вы введёте:
   • В Capitalist при создании карты (шаг 08)
   • В Claude при оплате подписки в поле «Billing Address» (шаг 10)

⚠ Адрес должен на 100% совпадать с городом прокси. Прокси в Jersey City — адрес в Jersey City. Не Нью-Йорк, не Делавер.
06
Проверка отпечатков (Pre-flight)
🎯Перед регистрацией в Claude убедитесь, что защита работает идеально. Все проверки — внутри профиля Dolphin!
Scamalytics — Fraud Score от 0 до 15
Откройте сайт в Dolphin → проверьте свой IP. Fraud Score должен быть 0–15 (зелёный). Если больше 30 — смените прокси.
scamalytics.com — проверка Fraud Score IP
Pixelscan — надпись «Consistent»
Проверяет, совпадают ли отпечатки браузера с IP. Должна быть зелёная надпись Consistent. Если красная — пересоздайте профиль в Dolphin.
pixelscan.net — проверка отпечатков браузера
Whoer — анонимность 100%
Должен показывать 100% анонимность. Если меньше — проверьте, что Dolphin запущен с прокси и VPN не конфликтует.
whoer.net — проверка анонимности
✅Все три проверки прошли? Отлично — ваша «капсула» готова. Все дальнейшие действия выполняем только внутри Dolphin.
07
Номер телефона США
📱Физическая американская SIM-карта (Non-VoIP). Такие номера проходят верификацию Claude без проблем, в отличие от виртуальных.
Арендовать номер США на MobileSMS.io
1. Откройте MobileSMS.io → зарегистрируйтесь
2. Перейдите в Long Term Rentals → USA
3. Тип: строго Physical / Non-VoIP
4. Выберите сервис: Claude / Anthropic
5. Арендуйте номер → сохраните его
mobilesms.io — аренда физических номеров США
08
Виртуальная карта Capitalist
💳Белая дебетовая карта USD с американским биллинг-адресом. Требует верификацию по паспорту (KYC) — именно поэтому она надёжнее «серых» карт и не вызывает подозрений у Stripe.
Зарегистрироваться на Capitalist
Откройте capitalist.net → создайте аккаунт.
capitalist.net — платёжная платформа
Пройти верификацию (KYC)
В личном кабинете: загрузите скан загранпаспорта (или ID) + сделайте селфи. Без верификации выпуск карт недоступен. Обычно занимает 1–2 рабочих дня.
Выпустить виртуальную карту USD
После KYC: выберите виртуальную карту USD (Debit/Corporate) → выпустите.
Указать биллинг-адрес США
Укажите американский адрес из шага 05 как биллинг-адрес при выпуске карты. Город и штат должны совпадать с локацией прокси.
Пополнить карту на ~$110
Claude Max $100 + запас $10 на обслуживание карты. Проверьте тип карты на binlist.net — должно быть Debit.
09
Регистрация Claude
⚡Всё делаем внутри Dolphin — не в обычном Chrome! Держите вкладку MobileSMS открытой для приёма кода.
Зарегистрироваться в Claude
1. В Dolphin откройте claude.ai → «Sign up»
2. Введите почту Proton из шага 03 (email + пароль отдельно, НЕ «Continue with Google»)
3. Подтвердите email — код придёт на Proton Mail
claude.ai — регистрация
Верифицировать номер телефона
Claude попросит номер → введите номер из MobileSMS (шаг 07). Перейдите в MobileSMS и скопируйте пришедший SMS-код → вставьте в Claude.
Отправить тестовое сообщение
Напишите «Привет! Расскажи о себе». Получили ответ — аккаунт работает!
10
Оплата Claude Max ($100/мес)
💎Claude Max — полный доступ ко всем моделям без ограничений. Очень важная подписка для интенсива. Если вы её не купите, то ваш OpenClaw будет работать менее эффективно.
Оплатить Claude Max
1. В Dolphin (Claude открыт) → иконка профиля → Settings → Billing
2. Upgrade → выберите Max
3. Введите реквизиты карты Capitalist из шага 08
4. Биллинг-адрес — тот же американский адрес, что сохранили на шаге 05
5. Номер телефона — номер из MobileSMS (шаг 07)
6. Оплатите → готово!
Проверить подписку
Settings → Billing → должно быть написано «Max».
Войти на платформу Claude
Обязательный шаг для API-токена и подключения к OpenClaw.
platform.claude.com — платформа для API-токена
