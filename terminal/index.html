Что такое Терминал и CLI

Краткая инструкция для участников интенсива

💻 Определения

Терминал — это программа, где ты вводишь текстовые команды компьютеру.

CLI (Command Line Interface) — это способ работать с программой через команды в терминале, без кнопок и окон сайта.

🪟 Windows

  1. Нажми Win + R
  2. Введи cmd или powershell
  3. Нажми Enter
— или —
  1. Открой Пуск
  2. Найди PowerShell или Windows Terminal

🍎 macOS

  1. Нажми Cmd + Space
  2. Введи Terminal
  3. Нажми Enter
— или —
  1. Открой Applications → Utilities → Terminal
