# STYLE-GUIDE — оформление уроков (video-urok-N/index.html)

Единые правила вёрстки и подачи для всех уроков курса «ИИ-ВИЗАЦИЯ: OPENCLAW».
Цель — консистентность от урока к уроку и от сессии к сессии. Эталон — уроки 1–3.
Менять правила можно, но осознанно и сразу во всех уроках.

## 1. Дизайн-система

- **Палитра** (CSS-переменные в `:root`): тёмно-фиолетовый фон + фиолетовый акцент `--accent` + зелёный `--green`. Не вводить новые цвета — использовать переменные.
- **Шрифты:** `Onest` (текст) + `JetBrains Mono` (код, метки, команды).
- **Радиусы/отступы:** через `--radius`; карточки секций — `.section__card`.
- **Эмодзи:** в иконках блоков (`.note__icon`, заголовки промптов) — да. В `.section__title` — НЕТ (там номер через `.section__num`).

## 2. Структура урока

- Шапка `.header` (бейдж, заголовок, список тем) → `.progress-wrap` (прогресс-бар) → секции → `.footer`.
- Каждая секция: `.section` → `.section__header` (`.section__num` + `.section__title`) → `.section__card`.
- **Нумерация секций — сквозная, по порядку, без пропусков:** `00, 01, 02, …`. После любой вставки/переноса секций — перенумеровать ВСЕ `.section__num` подряд. Проверка: номера идут 00..N без дыр и дублей.
- Продвинутые/необязательные блоки — после `.section-divider` («Продвинутые настройки и автоматизация»).
- **Без блока «Онлайн-встреча»** в футере (убран во всех уроках; CSS-классы можно оставить).

## 3. ГЛАВНОЕ ПРАВИЛО: оформление промптов (копировать → отправить в Claude Code)

Единый шаблон для любого промпта, который студент копирует и отправляет:

```
[пояснение ДО промпта]      ← что делаем / что подставить (1–2 строки или note). Коротко.
<div class="prompt-block">   ← сам промпт
  <div class="prompt-block__title">📋 Промпт: <что> (в Claude Code)</div>
  <div class="prompt-block__text" id="...">...текст...</div>
  <button class="btn-copy" onclick="copyBlock('...', this)">📋 Скопировать промпт</button>
</div>
<div class="item" data-key="...">  ← ОДИН чекбокс ПОСЛЕ промпта = «сделано»
  ... «Отправить промпт в Claude Code → <результат>» + hint: как проверить
</div>
```

Правила:
- **Пояснение — всегда ДО** промпта (контекст до действия). **Чекбокс-завершение — всегда ПОСЛЕ** промпта.
- **Куда отправлять — только в заголовке** промпта: `(в Claude Code)`. Не дублировать в тексте.
- **Никогда не разбивать «скопировать» и «вставить» на два чекбокса.** Кнопка «Скопировать» уже копирует; чекбокс один — «отправил и получил результат».
- Пишем **«отправьте в Claude Code»**, НЕ «отправьте агенту» (студенты путают «агента» с самим ботом OpenClaw).
- Если перед промптом нужен скачанный файл (скилл/набор): чекбокс «Скачать и перенести папку в проект» (ДО) → промпт → чекбокс «Отправить промпт» (ПОСЛЕ).

## 4. Команды в терминале

- Одиночная команда — `.cmd-copy` (с кнопкой копирования). Набор команд — `.code-block`.
- **Mac и Windows — оба варианта**, где команды различаются (Node.js, распаковка и т.п.). Текст инструкций — «на компьютере», не «на маке».
- Подключение к серверу — по алиасу `ssh my-server` (после настройки SSH-ключа в уроке), с оговоркой «или root@IP, если ключ не настраивали».
- Команды OpenClaw сверять со скиллом `openclaw-docs` (официальная дока). Не выдумывать флаги/ключи.

## 5. Кнопки скачивания (.zip с Google Drive)

- Единый класс **`.btn-dl`** (компактная кнопка, слева, не на пол-экрана). Текст: **⬇️ Скачать .zip**.
- Ссылка — **прямое скачивание**: `https://drive.google.com/uc?export=download&amp;id=<ID>` (НЕ `/file/d/.../view` — она открывает просмотр, а не качает).
- В HTML амперсанд экранировать: `&amp;`.
- Файл на Drive должен быть открыт «Всем, у кого есть ссылка».

## 6. Блоки-заметки (`.note`)

- `--info` (фиолетовый) — пояснение/контекст; `--green` — успех/совет/«работает сразу»; `--warn` (янтарь) — внимание/требования; `--alert` (красный) — критично/запрет.
- Внутри — `note__icon` (эмодзи) + текст. Списки — буллитами `•` через `<br>`, с нормальными отступами; не лепить «портянку» текста.

## 7. Таблицы (`.data-table`)

- Заголовок + строки. Для «команда/ошибка → объяснение» — две колонки: первая (термин/команда в `.mono`), вторая — простое пояснение «что значит и что делать».
- Параметры/спеки — каждый в своей строке (не «CPU / RAM» в одной).

## 8. Чек-листы (`.item[data-key]`)

- Прогресс хранится в `localStorage` по `data-key`. Ключи уникальные, осмысленные.
- При добавлении/удалении пунктов прогресс-бар считает сам (по числу `.item[data-key]`).

## 9. HTML-экранирование в текстах промптов

- В `prompt-block__text` плейсхолдеры вида `<gw>`, `<DATA_DIR>` (латиница после `<`) парсер съест как теги. Экранировать: `&lt;gw&gt;`. Кириллица после `<` (`<сервис>`) безопасна, но лучше тоже экранировать. `&` → `&amp;`.
- Кнопка «Скопировать» копирует `textContent` — после экранирования копируется корректный литерал.

## 10. Тон и язык

- Русский, простыми словами, для новичков без технической подготовки. Жаргон — объяснять одной фразой.
- Без авторского «я» («там я показываю») — нейтрально («в видео показано»).
- «Если что-то не работает» — отправить ошибку/задачу в Claude Code (там скилл `openclaw-docs`), он чинит. Это дефолтный способ решения проблем во всех уроках.

## 11. Процесс правок (важно)

- Контент уроков — ВСЕГДА из живого репозитория `stavzzz/open-sites` (свежий клон во временную папку, после — удалить).
- Перед пушем: проверить весь дифф; HTML-теги сбалансированы; нумерация секций цела; `copyBlock` id существуют; кнопки/ссылки рабочие.
- Дизайн-критичные правки — проверять рендером (скриншот) перед пушем.
