01
Редактор и Claude Code
видео 1
🎯Что получите в этой части: редактор Visual Studio Code и работающий внутри него Claude Code. После неё агент выполняет ваши задачи текстом.
Скачать и установить Visual Studio Code
Бесплатный редактор от Microsoft. Сайт определит вашу систему сам — нажмите синюю кнопку.
macOS: распакуйте архив и перетащите приложение в «Программы».
Windows: запустите установщик, галочки оставьте по умолчанию.
code.visualstudio.com — скачать редактор
Запустить редактор и найти три элемента
Остальное в интерфейсе пока не понадобится:
• Explorer — список файлов, верхняя иконка слева
• Extensions — расширения, иконка с квадратиками
• Терминал — панель снизу, меню Terminal → New Terminal
Установить расширение Claude Code
Откройте Extensions → наберите в поиске claude code → у расширения от Anthropic нажмите Install.
Войти в свою подписку Claude
Запустите Claude Code и наберите /login. Откроется браузер — подтвердите вход тем аккаунтом, на который оформлена подписка Claude Max.
💡VPN должен быть включён. Порядок тот же, что и в подготовке: сначала VPN, потом вход в Claude.
Отправить первый запрос и получить ответ
Напишите что-нибудь простое, например: «расскажи, что ты умеешь делать на моём компьютере». Ответ пришёл — редактор и агент работают.
Если пойдёте по пути Codex вместо Claude Code

Codex — такой же агент, только от OpenAI и по подписке ChatGPT. Ставится рядом и Claude Code не мешает.

Берите его, если основная подписка у вас ChatGPT. Команды и логика работы совпадают.

Основная линия интенсива идёт через Claude Code: промпты в связках написаны под него.

✅Часть 1 пройдена, если: редактор открывается, Claude Code внутри него отвечает на ваш вопрос.
02
Окружение и защита
видео 2
🎯Что получите в этой части: рабочую папку под проект, установленное окружение и защиту, при которой агент не меняет файлы за пределами этой папки.
Создать рабочую папку и открыть её как проект
Создайте папку в «Документах» — например, AI-office. Название запишите: оно понадобится на шаге с замком.
В редакторе: File → Open Folder → выберите эту папку. Агент работает внутри неё.
⚠️Одна папка на весь интенсив. Не раскладывайте связки по разным местам: защита настраивается ровно на одну папку.
Установить окружение: Homebrew и Node.js
Без них программы связок не запустятся. Ставятся один раз.
macOS: сначала Homebrew, потом Node.js.
Windows: только Node.js.
Проще попросить Claude Code — он поставит и проверит версию.
Подробная инструкция по окружению
🚫Зачем защита. Claude Code выполняет команды на вашем компьютере по-настоящему. При ошибке он может удалить нужные файлы. Дальше два пути на выбор: быстрый и основательный.
🟢 Быстрый путь — поставить DCG
🛡DCG — бесплатная программа-сторож. Она проверяет команду до запуска и блокирует опасную.

Что ловит: удаление файлов и папок целиком · откат и затирание истории проекта · опасные команды с базами и серверами.
Чего не ловит: действия злоумышленника, правку файлов напрямую, команды внутри скриптов.

Ставится одним промптом: скопируйте текст ниже и вставьте в Claude Code.
Установи и настрой мне DCG — защиту от опасных команд для Claude Code, из репозитория https://github.com/Dicklesworthstone/destructive_command_guard. Я новичок — веди по шагам простыми словами, подключи защиту как положено и в конце проверь, что она работает.
Установить DCG и проверить, что он работает
Отправьте промпт выше в Claude Code и пройдите по шагам, которые он подскажет. Проверку он выполнит сам.
github.com/Dicklesworthstone/destructive_command_guard
🟣 Основательный путь — замок на папку и броня
🔒Два отдельных чек-листа. Замок закрывает агенту доступ за пределы вашей папки. Броня — настройки самого Claude Code и бэкапы на случай, когда что-то всё-таки удалилось.

Порядок: сначала замок, потом броня. Каждый чек-лист заканчивается тестом, который показывает, что защита закрылась.
Пройти чек-лист «Замок на папку»
В чек-листе есть вариант для macOS и для Windows. В конце два теста: за пределы папки хода нет, внутри работа не сломана.
Чек-лист «Замок на папку» — macOS и Windows
Пройти чек-лист «Броня» под свою систему
Чек-листы разные — откройте свой.
Броня для macOS Броня для Windows
Включить резервное копирование компьютера
Последняя страховка, если файл всё-таки удалился.
macOS: Time Machine на внешний диск.
Windows: «История файлов» или резервное копирование на внешний диск.

03
Управление агентом
видео 3
🎯Что получите в этой части: шесть команд, которыми вы управляете агентом каждый день, и файл с правилами, который он читает перед работой.
⌨️Команды — короткие указания для Claude Code. Пишутся в чате и начинаются со слэша /. Наберёте слэш — Claude покажет меню со списком.
Разобрать шесть команд и попробовать каждую
КомандаЗачем нужна
/contextПоказывает, насколько заполнена память текущего диалога
/compactСжимает диалог, когда память почти кончилась, работа продолжается
/clearОчищает диалог и начинает с чистого листа
/modelВыбор модели: Opus — для сложного, Haiku — для простого и быстрого
/effortНасколько глубоко Claude думает: глубже — точнее, но дольше и дороже
/rewindОткат на шаг назад, если что-то пошло не так
💬Одна задача — один диалог. Память диалога ограничена. Чем длиннее переписка, тем дороже каждый следующий ответ и тем чаще агент теряет начало. Закончили задачу — /clear и начинайте следующую заново.
Создать файл CLAUDE.md в рабочей папке
CLAUDE.md — файл с постоянными правилами. Claude Code читает его первым и держит в памяти всё время работы.
Что туда пишут: чем вы занимаетесь, на каком языке отвечать, что запрещено трогать, где лежат важные файлы.
Написать его можно тем же промптом — попросите Claude Code задать вам вопросы и собрать файл из ответов.
Посмотреть режимы разрешений и включить нужный
По умолчанию Claude Code спрашивает разрешение перед каждым действием. В режиме Bypass Permissions он перестаёт спрашивать и работает без остановок.
Режим удобен на длинных задачах, но включайте его только после части 2: замок и защита уже стоят и ограничивают агента вашей папкой.
✅Часть 3 пройдена, если: вы вызвали каждую из шести команд, CLAUDE.md лежит в рабочей папке, режим разрешений выбран осознанно.
04
GitHub, скиллы и MCP
видео 4
🎯Что получите в этой части: аккаунт GitHub с токеном доступа, набор скиллов Superpowers и два подключённых сервиса — GitHub и браузер. Через GitHub вы забираете код связок, браузером агент открывает сайты и делает скриншоты.
Создать аккаунт на GitHub
GitHub — облако для проектов и кода. Оттуда вы будете забирать готовый код каждой связки.
github.com — регистрация
Включить двухфакторную защиту (2FA)
Это вход по второму коду с телефона. Без неё часть установок не проходит.
1. Settings → Password and authentication
2. Раздел Two-factor authentication → Enable
3. Выберите приложение-аутентификатор, отсканируйте QR-код, введите 6-значный код
4. Сохраните резервные коды в надёжном месте

Нет приложения на телефоне — поставьте бесплатное Google Authenticator.
Выпустить токен доступа (Classic PAT)
Токен — ключ-пароль, которым Claude заходит в ваш GitHub: создаёт репозитории, заливает файлы, включает публикацию сайтов. Нужен Classic-токен.
1. Tokens (classic) → Generate new token (classic)
2. Note: напишите Claude Code
3. Expiration: поставьте 90 дней
4. Scopes: отметьте все галочки верхнего уровня
5. Кроме одной: delete_repo не ставьте — тогда Claude не сможет удалить ваш репозиторий
6. Generate token → скопируйте сразу, второй раз GitHub его не покажет
🔒Токен — это ключ. Не выкладывайте его в чат, скриншот или git. Утёк — сразу отзовите и выпустите новый.
🔌MCP — способ подключить к Claude внешние сервисы: GitHub, браузер, таблицы. Подключили — и агент умеет с ними работать.
Подключаем два: GitHub и Playwright. Команды руками не набираете — копируете промпт, вставляете в чат, агент делает и проверяет сам.
Подключи мне официальный GitHub к Claude Code. Спроси у меня токен доступа (PAT), затем выполни команду, подставив мой токен вместо МОЙ_ТОКЕН: claude mcp add --transport http github https://api.githubcopilot.com/mcp/ --header "Authorization: Bearer МОЙ_ТОКЕН" Затем проверь список серверов: claude mcp list. Если github в статусе Connected — скажи мне. Если ошибка — покажи её и помоги починить.
Подключить GitHub — статус Connected
Вставьте промпт выше. Агент спросит токен и подключит сервис, затем покажет статус.
Установи мне MCP-сервер Playwright для Claude Code. Выполни команду: claude mcp add --scope user playwright -- npx -y @playwright/mcp@latest Затем проверь список серверов: claude mcp list. Если playwright в статусе Connected — скажи мне. Если ошибка — покажи её и помоги починить.
Подключить Playwright — статус Connected
Playwright даёт агенту браузер: он открывает сайты, делает скриншоты, кликает и заполняет формы. Пригодится, когда будете проверять свои страницы и разбирать чужие.
⚠️MCP расходуют память диалога. Держите включённым только то, чем пользуетесь. Остальное отключайте.
Установи набор скиллов Superpowers из репозитория https://github.com/obra/superpowers — зайди по ссылке, найди инструкцию установки для Claude Code и выполни её. После установки перезапусти сессию.
Установить набор скиллов Superpowers
Скилл — готовая инструкция-навык, которую Claude подхватывает сам под задачу. Не нужно каждый раз объяснять, как делать рутину.
Superpowers даёт 20 с лишним проверенных скиллов и команды /brainstorm, /write-plan, /execute-plan.
