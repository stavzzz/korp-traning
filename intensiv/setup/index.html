Редактор и Claude Code
видео 1
🎯Что получите в этой части: редактор Visual Studio Code и работающий внутри него Claude Code. После неё агент выполняет ваши задачи текстом.
Скачать и установить Visual Studio Code
Бесплатный редактор от Microsoft. Сайт определит вашу систему сам — нажмите синюю кнопку.
macOS: распакуйте архив и перетащите приложение в «Программы».
Windows: запустите установщик, галочки оставьте по умолчанию.
code.visualstudio.com — скачать редактор
Создать общую папку «Vibe Coding»
На рабочем столе или в «Документах» создайте папку и назовите её Vibe Coding. В ней будут лежать все ваши проекты.
Внутри — по отдельной папке на каждый проект: отдельная папка — отдельный проект. Диалоги Claude Code привязаны к папке: открыли папку проекта — агент видит её файлы и помнит прошлые сессии по ней.
Запустить редактор и найти три элемента
Остальное в интерфейсе пока не понадобится:
• Explorer — список файлов, верхняя иконка слева
• Extensions — расширения, иконка с квадратиками
• Терминал — панель снизу, меню Terminal → New Terminal
Установить расширение Claude Code
Откройте Extensions → наберите в поиске claude code → у расширения от Anthropic нажмите Install.
Войти в свою подписку Claude
Запустите Claude Code и наберите /login. Откроется браузер — подтвердите вход тем аккаунтом, на который оформлена подписка Claude Max.
💡VPN должен быть включён. Порядок тот же, что и в подготовке: сначала VPN, потом вход в Claude.
Отправить первый запрос и получить ответ
Напишите что-нибудь простое, например: «расскажи, что ты умеешь делать на моём компьютере». Ответ пришёл — редактор и агент работают.
Если пойдёте по пути Codex вместо Claude Code

Codex — такой же агент, только от OpenAI и по подписке ChatGPT. Ставится рядом и Claude Code не мешает.

Берите его, если основная подписка у вас ChatGPT. Команды и логика работы совпадают.

Основная линия интенсива идёт через Claude Code: промпты в связках написаны под него.

✅Часть 1 пройдена, если: папка Vibe Coding создана, редактор открывается, Claude Code внутри него отвечает на ваш вопрос.
02
Окружение и защита
видео 2
🎯Что получите в этой части: рабочую папку под проект, установленное окружение и защиту, при которой агент не меняет файлы за пределами этой папки.
Создать рабочую папку и открыть её как проект
Внутри «Vibe Coding» создайте папку проекта — например, AI-office. Название запишите: оно понадобится на шаге с замком.
В редакторе: File → Open Folder → выберите эту папку. Агент работает внутри неё.
⚠️Одна папка на весь интенсив. Не раскладывайте связки по разным местам: защита настраивается ровно на одну папку.
⚙️Окружение — программы, без которых код связок не запустится. Ставятся один раз. Команды руками не набираете: копируете промпт под свою систему и вставляете в чат Claude Code.
macOS. Установи мне Homebrew, затем Node.js последней LTS-версии. Я новичок — веди по шагам простыми словами. В конце выполни node -v и npm -v и покажи мне версии.
Windows. Установи мне Node.js последней LTS-версии. Я новичок — веди по шагам простыми словами. В конце выполни node -v и npm -v и покажи мне версии.
Установить окружение и увидеть версии
Отправьте промпт под свою систему. Готово, когда агент показал две версии: node и npm.
На macOS ставится Homebrew и Node.js, на Windows — только Node.js.
🚫Зачем защита. Claude Code выполняет команды на вашем компьютере по-настоящему. При ошибке он может удалить нужные файлы. Ставим сторожа, который проверяет команду до запуска.
🛡DCG — бесплатная программа-сторож. Проверяет команду до запуска и блокирует опасную.

Что ловит: удаление файлов и папок целиком · откат и затирание истории проекта · опасные команды с базами и серверами.
Чего не ловит: действия злоумышленника, правку файлов напрямую, команды внутри скриптов.
Установи и настрой мне DCG — защиту от опасных команд для Claude Code, из репозитория https://github.com/Dicklesworthstone/destructive_command_guard. Я новичок — веди по шагам простыми словами, подключи защиту как положено и в конце проверь, что она работает.
Установить DCG и проверить, что он работает
Отправьте промпт выше и пройдите по шагам, которые подскажет агент. Проверку он выполнит сам.
github.com/Dicklesworthstone/destructive_command_guard
Дополнительно: замок на папку и броня

Два отдельных чек-листа для тех, кто хочет закрыть агента жёстче. В основной путь интенсива они не входят — разбираем их отдельно.

Замок закрывает агенту доступ за пределы вашей папки: чек-лист «Замок на папку», есть вариант для macOS и для Windows.

Броня — настройки самого Claude Code и резервные копии: для macOS · для Windows.

Порядок: сначала замок, потом броня. Каждый чек-лист заканчивается тестом, который показывает, что защита закрылась.

03
Управление агентом Claude Code
видео 3
🎯Что получите в этой части: команды, которыми вы управляете агентом каждый день, разобранный интерфейс и файл с правилами, который агент читает перед работой.
⌨️Команды — короткие указания для Claude Code. Пишутся в чате и начинаются со слэша /. Наберёте слэш — Claude покажет меню со списком.
Разобрать команды и попробовать каждую
КомандаЗачем нужна
/contextПоказывает, сколько памяти диалога занято и сколько осталось
/compactСжимает диалог, когда память кончается: работа продолжается, начало не теряется
/clearОчищает диалог и начинает с чистого листа
/modelВыбор модели: Opus — для сложного, Haiku — для простого и быстрого
/effortНасколько глубоко Claude думает: глубже — точнее, но дольше и дороже
/doctorПроверяет, что Claude Code установлен правильно; показывает, что сломано
/rewindОткат на шаг назад, если что-то пошло не так
💬Одна задача — один диалог. Память диалога ограничена. Чем длиннее переписка, тем дороже каждый следующий ответ и тем чаще агент теряет начало. Закончили задачу — /clear и начинайте следующую заново.
Разобраться в интерфейсе: шесть мест, куда вы будете смотреть
• Открыть другой проект — File → Open Folder, выбираете нужную папку внутри «Vibe Coding»
• Выбор модели — переключается в интерфейсе или командой /model
• Режим размышления — Thinking и /effort: чем глубже, тем дольше и дороже ответ
• Остаток памяти диалога — виден в интерфейсе и по команде /context
• Список сессий — панель слева: прошлые диалоги по этой папке, к любому можно вернуться
• Аккаунт и лимиты — сколько запросов израсходовано по подписке
Указать агенту конкретный файл через собаку
Наберите в чате @ — появится список файлов проекта. Выберите нужный, и агент будет работать именно с ним, а не искать по всей папке.
Так же добавляют картинки и документы: @отчёт.pdf, @скриншот.png.
Найти режимы разрешений и включить Bypass Permissions
По умолчанию Claude Code спрашивает разрешение перед каждым действием. В режиме Bypass Permissions он перестаёт спрашивать и работает без остановок.
Режим экономит время на длинных задачах. Включайте его после части 2: DCG уже проверяет команды.
📄CLAUDE.md — файл с постоянными правилами. Claude Code читает его первым и держит в памяти всё время работы. Лежит в корне папки проекта.
Ниже — образец. Скопируйте, замените текст под себя и сохраните как CLAUDE.md.
образец CLAUDE.md
# Кто я Владелец студии интерьерного дизайна, в команде 6 человек. Не программист. # Что за проект Внутренние ИИ-помощники студии: бот-секретарь, учёт расходов, база знаний по услугам. # Как отвечать - По-русски, коротко, без лишней теории. - Сначала результат, потом объяснение. - Незнакомый термин объяснять одной строкой при первом упоминании. - Перед изменением файлов показывать план и ждать моего подтверждения. # Что не трогать - Файл .env и любые ключи, токены, пароли. - Папку archive. - Ничего за пределами этой папки. # Где что лежит - docs/ — инструкции и регламенты студии - bots/ — код ботов - README.md — общее описание проекта
Создать свой CLAUDE.md в папке проекта
Можно править образец руками, а можно собрать файл разговором — вставьте промпт ниже.
Собери мне файл CLAUDE.md для этого проекта. Задай мне по одному вопросу за раз: кто я, чем занимается мой бизнес, как ты должен со мной разговаривать, что тебе запрещено трогать, где что лежит в папке. Из моих ответов составь файл и сохрани его в корне проекта.
✅Часть 3 пройдена, если: вы вызвали каждую команду из таблицы, нашли в интерфейсе выбор модели, список сессий и остаток памяти, указали файл через @, и в папке проекта лежит ваш CLAUDE.md.

GitHub, скиллы и MCP
видео 4
🎯Что получите в этой части: аккаунт GitHub с токеном доступа, набор скиллов Superpowers и два подключённых сервиса — GitHub и браузер. Через GitHub вы забираете код связок, браузером агент открывает сайты и делает скриншоты.
Создать аккаунт на GitHub
GitHub — облако для проектов и кода. Оттуда вы будете забирать готовый код каждой связки.
github.com — регистрация
Включить двухфакторную защиту (2FA)
Это вход по второму коду с телефона. Без неё часть установок не проходит.
1. Settings → Password and authentication
2. Раздел Two-factor authentication → Enable
3. Выберите приложение-аутентификатор, отсканируйте QR-код, введите 6-значный код
4. Сохраните резервные коды в надёжном месте

Нет приложения на телефоне — поставьте бесплатное Google Authenticator.
Выпустить токен доступа (Classic PAT)
Токен — ключ-пароль, которым Claude заходит в ваш GitHub: создаёт репозитории, заливает файлы, включает публикацию сайтов. Нужен Classic-токен.
1. Tokens (classic) → Generate new token (classic)
2. Note: напишите Claude Code
3. Expiration: поставьте 90 дней
4. Scopes: отметьте все галочки верхнего уровня
5. Кроме одной: delete_repo не ставьте — тогда Claude не сможет удалить ваш репозиторий
6. Generate token → скопируйте сразу, второй раз GitHub его не покажет
🔒Токен — это ключ. Не выкладывайте его в чат, скриншот или git. Утёк — сразу отзовите и выпустите новый.
🔌MCP — способ подключить к Claude внешние сервисы: GitHub, браузер, таблицы. Подключили — и агент умеет с ними работать.
Подключаем два: GitHub и Playwright. Команды руками не набираете — копируете промпт, вставляете в чат, агент делает и проверяет сам.
Подключи мне официальный GitHub к Claude Code. Спроси у меня токен доступа (PAT), затем выполни команду, подставив мой токен вместо МОЙ_ТОКЕН: claude mcp add --transport http github https://api.githubcopilot.com/mcp/ --header "Authorization: Bearer МОЙ_ТОКЕН" Затем проверь список серверов: claude mcp list. Если github в статусе Connected — скажи мне. Если ошибка — покажи её и помоги починить.
Подключить GitHub — статус Connected
Вставьте промпт выше. Агент спросит токен, подключит сервис и покажет статус.
Установи мне MCP-сервер Playwright для Claude Code. Выполни команду: claude mcp add --scope user playwright -- npx -y @playwright/mcp@latest Затем проверь список серверов: claude mcp list. Если playwright в статусе Connected — скажи мне. Если ошибка — покажи её и помоги починить.
Подключить Playwright — статус Connected
Playwright даёт агенту браузер: он открывает сайты, делает скриншоты, кликает и заполняет формы. Пригодится, когда будете проверять свои страницы.
⚠️MCP расходуют память диалога. Держите включённым только то, чем пользуетесь. Остальное отключайте.
Установи набор скиллов Superpowers из репозитория https://github.com/obra/superpowers — зайди по ссылке, найди инструкцию установки для Claude Code и выполни её. После установки перезапусти сессию.
Установить набор скиллов Superpowers
Скилл — готовая инструкция-навык, которую Claude подхватывает сам под задачу. Не нужно каждый раз объяснять, как делать рутину.
Superpowers даёт 20 с лишним проверенных скиллов и команды /brainstorm, /write-plan, /execute-plan.
github.com/obra/superpowers

05
Покупка рабочего сервера
видео 5
🎯Что получите в этой части: отдельный сервер под OpenClaw, его IP-адрес и пароль. На этом сервере дальше будут работать все ваши боты.
🚨Это второй сервер, а не тот, что из подготовки. На первом стоит VPN — его не трогаем. OpenClaw ставится на отдельный чистый сервер: без VPN, без других сервисов.
Аккаунт хостинга можно взять тот же — просто создайте в нём ещё один сервер.
🚫Сервер не должен принадлежать российской компании. Дело не в том, где физически стоит железо: IP у вас будет зарубежный. Дело в том, чьей компании принадлежат стойки и этот IP.
Российские хостеры (Aeza, Timeweb, Reg.ru и подобные) сдают зарубежные локации, но владелец — российское юрлицо, и его диапазоны IP известны. OpenAI, Anthropic и Google такие диапазоны часто режут по гео или блокируют.
Итог: модели то работают, то нет, бот молчит, а причину не видно.

06
Вход на сервер по ключу
видео 6
🎯Что получите в этой части: вход на сервер одной короткой командой, без пароля. Дальше Claude Code сам подключается к серверу и ставит на него OpenClaw.
🔑Подключение по ключу. Вместо пароля ваш компьютер предъявляет серверу криптографический ключ. Это быстрее и безопаснее: пароль к такому серверу подобрать нельзя.

Алиас — короткое имя сервера. Вместо длинной команды с IP и вводом пароля каждый раз получается одна: ssh my-server.
📋Порядок действий:
1. Скопируйте промпт ниже.
2. Впишите в него реальный IP вашего сервера вместо подсказки в скобках.
3. Откройте новую сессию Claude Code.
4. Включите режим Bypass Permissions.
5. Отправьте промпт и выполняйте указания агента.

Что-то непонятно — спрашивайте прямо там же, присылайте скриншоты и текст из терминала.
Привет! Я только что получил доступ к новому серверу. Его IP-адрес: (ВПИШИТЕ СЮДА IP ВАШЕГО СЕРВЕРА) Помоги мне настроить подключение к этому серверу по SSH-ключу без пароля. Дай пошаговый план и проведи меня по нему, учитывая что: — я новичок и, скорее всего, SSH-ключа у меня ещё нет — нужно будет его сгенерировать; — файла ~/.ssh/config у меня тоже может не быть — его нужно создать или дополнить; — мне нужно, чтобы подключение работало и здесь, в Claude Code, и из любого терминала на моём устройстве — одной короткой командой, например ssh my-server. План должен покрывать: — Проверку, есть ли уже SSH-ключ на моём компьютере (в папке ~/.ssh/). — Генерацию нового ключа (ed25519), если ключа нет — с понятным объяснением, что такое приватный и публичный ключ и зачем passphrase. — Копирование публичного ключа на сервер командой ssh-copy-id — с одним вводом пароля root. — Добавление алиаса в ~/.ssh/config (Host, HostName, User, IdentityFile), чтобы подключаться коротко. — Проверку, что подключение работает без пароля. — Отключение парольного входа в /etc/ssh/sshd_config, чтобы сервер нельзя было брутфорсить — со страховкой «второй открытый терминал на случай, если что-то пойдёт не так». ВАЖНО: — Объясняй каждый шаг простыми словами — что мы делаем и зачем. — После каждого шага дождись моего подтверждения, прежде чем переходить к следующему. — Если я где-то ошибусь, например вставлю команду не туда — поправь и объясни, в чём была ошибка. Отвечай на русском, на «ты».
Создать SSH-ключ и положить его на сервер
Агент проверит, есть ли ключ, создаст новый при необходимости и скопирует публичную часть на сервер. Пароль root вы введёте один раз — последний.
Настроить короткое имя и зайти без пароля
Проверка простая: выполните ssh my-server — вы должны попасть на сервер, и пароль не спросят.
Команда работает в любом терминале, включая встроенный в Visual Studio Code.
⚠️Второй терминал держите открытым. Перед отключением парольного входа откройте вторую сессию к серверу и не закрывайте её. Если в настройках окажется ошибка, вы почините её из этого окна, а не потеряете доступ к серверу.
Отключить вход по паролю
После этого на сервер пускает только ваш ключ. Подобрать пароль перебором станет невозможно.
